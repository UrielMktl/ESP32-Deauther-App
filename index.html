📶 Redes WiFiobjetivo

La app manda comandos (SCAN, DEAUTH, STOP, CLONE…) y el ESP32 los ejecuta en la red que elijas.

👯 Clonador de red (Evil-Twin educativo)

  1. Escanea redes en la app o Web UI.
  2. Clona la seleccionada: mismo SSID y canal. O ingresa los datos a mano: SSID (máx 32), canal 1-13 y pass del AP falso (vacío = abierta, ≥8 = WPA2).
  3. Detén el clon cuando termines: el ESP32 restaura su AP ESP32-Deauther.

API: POST /api/clone (con net_num+pass o ssid+channel+pass), POST /api/clone_stop, GET /api/clone_status. BLE: CLONE_NET <num> [pass], CLONE <ssid>|<canal>|<pass>, CLONE_STOP.

⚠ El clon y el deauth usan el mismo radio: al iniciar uno se apaga el otro. Solo en redes propias.

🚀 Puesta en marcha

  1. Flashea el firmware: rápido por el flasheador web (USB) (soporta ESP32 y ESP32-S3) o con PlatformIO desde firmware/.
  2. Instala el APK en Android (permite “orígenes desconocidos”). En iPhone necesitas una Mac con Xcode.
  3. Conéctate al WiFi del ESP32: SSID ESP32-Deauther, password esp32wroom32.
  4. Abre la app y elige WiFi (IP 192.168.4.1) o Bluetooth. Usa el usuario/password que definiste en secrets.h.
  5. BLE: pulsa “Escanear”, elige ESP32-Deauther, acepta los permisos Bluetooth y escribe tu password. La app ya lo trae escrito.
  6. Escanea redes, selecciona una, elige un Reason code y pulsa Deauth. Para clonar, usa la sección Clonador e ingresa SSID/canal/pass.

⚠ “Deauth all” apaga el WiFi del ESP32: para pararlo, resetea la placa. El ESP32-S3 comparte radio WiFi+BLE; si el BLE va lento, usa una cosa a la vez.
